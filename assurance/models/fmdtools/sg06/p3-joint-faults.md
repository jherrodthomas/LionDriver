The sets are in [`p3-minimal-sets.json`](p3-minimal-sets.json).

## Limits

- One road phase (approach). [P2](p2-single-faults.md) shows what following at a steady gap changes for single faults.
- Pruning supersets assumes nothing more is learned from a superset of a set already found. A further fault can add a cue (a supply loss lets the driver feel the end of ACC deceleration), so a superset can be free of TE-06 in the model; that does not change which sets are minimal.
- Sets above order 4 are not run, so a tree set that needs both BE-6.06 and a siren failure is explained only if it has at most 2 events.

## Limits

- One road phase (mid-curve). [P2](p2-single-faults.md) shows what the straight changes for single faults.
- Pruning supersets assumes nothing more is learned from a superset of a set already found. A further fault can add a cue (a supply loss lets the driver feel the end of LKA torque), so a superset can be free of TE-02 in the model; that does not change which sets are minimal.
- Sets above order 4 are not run.

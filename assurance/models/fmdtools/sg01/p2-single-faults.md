# SG-01 single faults (step P2)

> **Synthetic (DSR-12).** Generated by [`sweep.py`](sweep.py) from the fmdtools model ([`model.py`](model.py), [`events.yaml`](events.yaml)); do not edit by hand. No evidence credit: the results point reviewers at possible gaps in the WP-A-04 tree, and a tree changes only after a person reviews the finding.

Each of the 26 failure modes is injected alone, 0.5 s into a run, in each phase. A cell gives the TE-01 branch the run reaches and when (seconds after the injection): **excess**, excessive torque not limited by the EPS (G1.1); **unwanted**, torque the driver does not want (G1.2); **stale**, stale torque held beyond the FTTI (G1.3); **overlap**, stock LKA with the item beyond the FTTI (G1.4). The FTTI is 0.5 s; torque the driver does not want counts once it has lasted the SG-05 release time, 0.2 s.

## Phases

| Phase | Item engaged at the start | Driver | Source |
|---|---|---|---|
| engaged | yes | none | The item is engaged and the driver keeps it engaged (G1.1, G1.3, G1.4) |
| brake | yes | brake | The driver disengages by braking: the brake frame (0x226) shows the press and the PCM drops cruise (0x1D2), so the envelope sees both (TSR-301, TSR-302) (G1.2.2) |
| cancel | yes | cancel | The driver disengages with the cancel button: only the PCM cruise state (0x1D2) shows it (TSR-301) (G1.2.2) |
| off | no | none | The item is not engaged and the driver does not engage it (G1.2.1) |

## 03_Architecture_Boundary

*Architecture Boundary — Item Definition*

**Item Scope.** Aftermarket supervised SAE Level 2 feature on the Toyota Corolla, 12th generation (E210), TSS 2.0 (reference configuration, WP-C-01), on limited-access highways only (WP-C-02). Lateral (LKA torque) and longitudinal (ACC) control with driver monitoring; the panda safety MCU envelope bounds actuation. Experimental Mode is INCLUDED in this variant (D-08 option B).

**Boundary Diagram.** See WP-C-01 §3.3. Vehicle ECUs (EPS, PCM, ABS/VSC, camera, radar) are outside the item, with AoUs.

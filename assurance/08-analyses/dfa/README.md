# Fault tree AND gates against the dependent failure analysis

[`dfa-gates.md`](dfa-gates.md) checks every AND gate of the [WP-A-04](../WP-A-04-system-fta-fmea.md) fault trees
against the independence claims of [WP-A-03](../WP-A-03-dependent-failure-analysis.md) (§5.1), using a shared-resource
map of the item. It is generated by `dfa_gates.py` from `and-gates.yaml` (each gate's elements and claim) and
`shared-resources.yaml` (what each element depends on, and the DFIs that analyse it); edit those and run
`python3 dfa_gates.py` (CI runs `--check` and `test_dfa_gates.py`).

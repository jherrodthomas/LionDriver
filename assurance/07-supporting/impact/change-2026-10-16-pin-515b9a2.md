## 2. Finding SM-F1: an edge while MAIN_ON = 0 opens the engagement window

Found while writing the record from the code at `515b9a2`. Not found by the back-to-back test, whose harness keeps the heartbeat engaged.

| Field | Value |
|---|---|
| Requirement | SWSR-405(c): "CRUISE_ACTIVE changing to 1 while MAIN_ON = 0 shall be an RX fault at once, without tolerance" (from B2B-03 / BB-C-02) |
| Code | `pcm_cruise_check` (`safety.h:718-727`) opens the window before `toyota_cruise_main_check(true)` (`modes/toyota.h:127-145`, called at :271-273) runs on the same `0x1D2` frame. The main check clears `controls_allowed`, which is not yet set, and leaves `pcm_engage_pending` set. `pcm_engage_check` (`safety.h:476-488`) does not look at MAIN_ON |
| Effect | If the heartbeat reports engaged within 1 s of such an edge, the safety task grants authority while MAIN_ON = 0. The main check revokes it once the mismatch has lasted more than 150 ms (`TOYOTA_CRUISE_MAIN_TOLERANCE_US`). With the heartbeat already engaged at the edge, the grant and its clearing happen in the same call, as before (record T8) |
| Evidence | A throwaway unit-level probe at `515b9a2`, reference build, `TestToyotaSafetyTorque` setup (not committed): main off, edge with heartbeat engaged = 0 → no authority; heartbeat engaged at 50 ms, safety task → **authority granted**; still granted at 100 ms; cleared at 150 ms. Host test only, no hardware |
| Bound | Authority with MAIN_ON = 0 for at most about the 150 ms tolerance plus one frame, and only when the host reports engaged while the car's cruise main is off. That is inside the TSR-405 detection limit (≤ 0.2 s) but against the "at once" sentence of SWSR-405(c) |
| Record | T1a and T1b say "MAIN_ON is not checked (finding SM-F1)"; the T8 guard keeps the immediate refusal only for the heartbeat-engaged case. SWSR-405 is already Partial in the WP-W-02 Baseline; its (c) entry now names SM-F1 |
| Proposed fix (not in this change) | Close the window when cruise becomes active while main is off, e.g. clear `pcm_engage_pending` in the `from_pcm_cruise` branch of `toyota_cruise_main_check`, with a unit test of the probe above. An opendbc change, then a pin bump |

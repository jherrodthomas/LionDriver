# Fault-injection plant model: results

> **Synthetic data (DSR-12).** Generated by [`plant/report.py`](../plant/report.py); do not edit by hand. Models around the real panda safety code; nothing here is measured. **No evidence credit**: simulation earns credit only once the WP-V-02 §5.3 fidelity case is approved for the scenario family (DQ-139). Results rank risks and guide tests only, until the model is validated against Corolla logs. Timing results go to the safety-concept session for WP-S-04; they are not entered in the MSR rating tables, which allow `measured | code_derived | unknown` only. Method and limits: [README](../README.md).

Times are seconds from fault onset. Deviation is the lateral offset from the offset at fault onset; negative is to the right (outside of the left curve). Lane-line thresholds: body edge on the line, (lane width − 1.781 m) / 2 = **0.61 m** in a 3.0 m lane (narrowest ODD-H lane) and **0.96 m** in a 3.7 m lane. Speed 110 km/h (the ODD-H bound, DQ-260) unless the case names another; rows ending -OS repeat the first case of each fault family at 120 km/h, outside the ODD, as margin cases. Curve: a clothoid over 100 m into a left arc with R = v²/1.5 m/s² (inside the ODD); N-3 uses R_ODD = v²/2.5 m/s²; a road named KS-xx is read from that scenario's OpenDRIVE file (ego lane −2, [`scenarios/xodr`](../scenarios/xodr/)). Panda: reference build (`LIONDRIVER_REFERENCE`, safety parameter 73); IWDG nominal timeout from the values the firmware writes: 90 ms. For safety parameter 73 the release build and this build (`ALLOW_DEBUG`) differ only in the SecOC flag, which the reference car does not set.

# LionDriver

**Open Driving. Engineered for Safety.**

An open-source automotive driving platform derived from [comma.ai/openpilot](https://github.com/commaai/openpilot), being developed with integrated functional safety, Safety of the Intended Functionality (SOTIF), cybersecurity, and transparent engineering assurance.

### Project Mission

LionDriver explores what it takes to transform an existing open-source driving system into a rigorously engineered, evidence-backed automotive reference platform.

The objective is not simply to demonstrate driving functionality, but to establish a reproducible engineering lifecycle connecting hazards, safety requirements, architecture, implementation, verification, and assurance evidence.

### Engineering Scope

- **ISO 26262:** Functional safety management, concept development, system/hardware/software development, production and operational lifecycle, supporting processes, and safety analyses.
- **ISO 21448:** SOTIF, performance limitations, triggering conditions, foreseeable misuse, and scenario-based validation.
- **ISO/SAE 21434:** Automotive cybersecurity engineering, threat analysis, security requirements, and vulnerability management.
- **ISO/PAS 8800:** Safety considerations for AI-based automotive systems.
- **UL 4600:** Safety-case and autonomous-system assurance principles, where applicable.
- **Verification and Validation:** Simulation, software-in-the-loop, hardware-in-the-loop, fault injection, and controlled vehicle testing.

### Initial Reference Platform

**2020 Toyota Corolla LE — U.S. Market**

The initial reference configuration will be established using an identified vehicle, controlled software and hardware baselines, and documented operating assumptions.

Future vehicle configurations will require impact analysis and supporting evidence before being included in the assured configuration scope.

### Project Status

**Research and development — not safety-certified or approved for unsupervised public-road operation.**

No claim of ISO 26262 compliance, ASIL D capability, or suitability for driverless operation is made for the current project baseline. Safety claims will be limited to configurations and evidence that substantiate them.
